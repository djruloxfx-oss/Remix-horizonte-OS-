TITULO: Revisar y Mejorar Ensayos Académicos
CONTENIDO:
Analiza, corrige y eleva la calidad de tus ensayos académicos optimizando gramática, coherencia, argumentación y estilo formal según el nivel educativo.
El objetivo de este prompt es elevar la calidad y solidez de los ensayos académicos mediante una revisión integral que optimiza gramática, estilo y coherencia argumentativa.
Está especialmente recomendado para quienes trabajan en el ámbito de educacion y necesitan analiza, corrige y eleva la calidad de tus ensayos académicos optimizando gramática, coherencia, argumentación y estilo formal según el nivel educativo. Su estructura clara permite obtener resultados consistentes sin necesidad de ajustar el prompt cada vez.
Una de las principales ventajas es que corrige errores básicos de ortografía, gramática y puntuación., lo que ahorra tiempo y mejora la calidad de los resultados. Al usar este prompt, la IA entiende exactamente qué se espera de ella y en qué formato debe responder.

 ¿Qué hace el prompt?
Corrige errores básicos de ortografía, gramática y puntuación.
Evalúa la claridad y coherencia general del texto.
Sugiere ajustes simples para mejorar el estilo académico.
 ¿Cómo usar este prompt? 
Copia y pega el prompt en tu modelo de IA preferido.
Completa las variables:
[ENSAYO] Pega el texto completo del ensayo.
Ejecuta el prompt para recibir tu versión corregida y clara.
[AREA] Ej.: 'derecho'
[ENSAYO] Ej.: 'ensayo argumentativo sobre el impacto de las redes sociales en adolescentes'
[NIVEL] Ej.: 'pregrado'

 Tips 
Indica el nivel académico y el área del ensayo.
Evita incluir formato o tablas para un análisis limpio.
Asegúrate de pegar todo el texto completo del ensayo.

 ¿Para quién es?
Está pensado para estudiantes universitarios, investigadores en formación y profesionales que necesitan presentar trabajos escritos formales. También es útil para docentes que quieren agilizar la revisión de borradores y para quienes buscan pulir su redacción académica sin depender de un corrector humano.

 ¿Qué problema resuelve?
Resolver la dificultad de detectar errores sutiles en textos largos y la falta de objetividad al revisar el propio trabajo. Muchas veces, al releer un ensayo, se pasan por alto fallos de coherencia, repeticiones o giros poco formales que restan calidad al argumento. Este prompt ayuda a identificar esos puntos ciegos y ofrece una corrección estructurada y clara.

 Casos de uso prácticos
Un estudiante de maestría en derecho que necesita ajustar el tono de su monografía final para cumplir con el rigor de una revista especializada.
Un investigador en psicología que quiere verificar que sus hipótesis se expliquen con claridad antes de enviar un artículo a revisión por pares.
Un alumno de pregrado en educación que debe entregar un ensayo argumentativo y nota que su redacción es confusa en varios párrafos.
Un profesional que redacta un informe técnico y desea asegurarse de que la estructura sea lógica y la gramática impecable.

 Consejos para mejores resultados
Indica siempre el nivel académico exacto (pregrado, maestría, doctorado) y el área de conocimiento; así la IA ajusta el vocabulario y la profundidad de las correcciones.
Pega el ensayo completo sin formato adicional (sin tablas, negritas o listas complejas) para que el análisis sea limpio y se centre en el contenido.
Si el texto es muy extenso, divídelo en partes lógicas (introducción, desarrollo, conclusión) y ejecuta el prompt por separado para mantener la coherencia en cada sección.

TITULO: horizonte-biblioteca (2)
CONTENIDO:
Devuelve una tabla con: coste total, tiempo, fiabilidad, simplicidad, reversibilidad, riesgos y veredicto.
Después indica la opción recomendada, el motivo principal, el plan B y la siguiente acción.
¿Qué hace el prompt?
Convierte una decisión u opciones propuestas en una evaluación estructurada.
Devuelve una tabla comparativa con siete criterios: coste total, tiempo, fiabilidad, simplicidad, reversibilidad, riesgos y veredicto.
Obliga a cerrar el análisis con una recomendación clara.
Identifica el motivo principal de la opción recomendada.
Propone un plan B si la opción principal falla o no conviene.
Define una siguiente acción concreta para pasar del análisis a la ejecución.
Aplica un enfoque orientado a resultados, priorizando decisiones prácticas y verificables.
¿Cómo usar este prompt?
Copia el prompt en tu conversación con la IA.
Describe la decisión, proyecto o situación que quieres evaluar.
Añade las opciones disponibles, si las conoces.
Indica restricciones relevantes: presupuesto, plazo, nivel de riesgo aceptable o recursos disponibles.
Envía el prompt para recibir la tabla de evaluación.
Revisa el veredicto, la opción recomendada y el plan B.
Ejecuta la siguiente acción propuesta o pide ajustes si falta contexto.
Tips
Incluye cifras o rangos de coste y tiempo cuando los tengas.
Especifica si prefieres minimizar riesgo, gasto, tiempo o complejidad.
Menciona consecuencias irreversibles, como compras, contratos o cambios de configuración.
Si hay muchas opciones, pide primero una preselección de las más viables.
Usa el plan B como criterio de contingencia antes de comprometerte.
Pide que justifique cada veredicto si necesitas auditar la recomendación.
¿Para quién o para qué es?
Es un prompt para personas que deben tomar decisiones con varias alternativas y quieren una evaluación rápida, ordenada y accionable. Sirve para comparar opciones de compra, herramientas, proveedores, rutas de trabajo, planes de proyecto o cambios operativos, convirtiendo un análisis difuso en una recomendación concreta con contingencia y siguiente paso.
¿Qué problema resuelve?
Resuelve el problema de las decisiones mal estructuradas, donde las opciones se comparan por intuición o se analizan sin criterios comunes. Al forzar una tabla con coste, tiempo, fiabilidad, simplicidad, reversibilidad y riesgos, el prompt hace visibles los compromisos de cada alternativa y evita recomendaciones vagas, asegurando que la respuesta termine en una elección, un motivo, un respaldo y una acción.
Casos de uso prácticos
Elegir entre dos o más proveedores, tarifas o suscripciones.
Comparar herramientas de software para un flujo de trabajo.
Decidir entre reparar, sustituir o alquilar un equipo.
Evaluar opciones de viaje, alojamiento o transporte.
Seleccionar una estrategia de marketing con distinto coste y riesgo.
Comparar planes de implementación para un proyecto o negocio.
Decidir si externalizar una tarea o resolverla internamente.
Valorar cambios de proceso antes de modificar configuraciones o contratos.
Consejos para mejores resultados
Define el objetivo final antes de enviar el prompt.
Indica el presupuesto máximo y la fecha límite.
Explica qué criterio pesa más: coste, rapidez, fiabilidad o facilidad de reversión.
Aporta datos reales de cada opción cuando estén disponibles.
Señala riesgos inaceptables, como pérdida de datos, gastos no reembolsables o dependencia de un proveedor.
Pide una escala o puntuación para cada criterio si quieres comparar opciones de forma más objetiva.
Solicita una versión resumida de una línea si solo necesitas decidir con rapidez.
